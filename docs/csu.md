# 中南大学教务系统接入

本地开发版新增。入口是左侧「中南教务」，或设置中的「中南大学教务 → 连接 / 管理」。现有 0.1.3 安装包不含此功能。

1. 选择近 7 天或 30 天通知，点击「打开学校登录窗口」。
2. 在学校统一认证页面输入账号密码，或使用学校提供的扫码方式，完成验证码。密码由学校页面接收。
3. 进入教务系统后，回到 Daymark 点击「我已登录，开始同步」。保持学校窗口打开；程序也会检测登录完成。连接后可直接调整读取范围并点同步，不必重新登录。
4. 支持学生个人中心的教务通知和「更多 → 已收公告」列表，读取通知详情及分页。当前接入的是 `csujwc.its.csu.edu.cn` 内的通知，不采集本科生院官网。
5. 在「大模型整理」启用自动整理后，新采集的站内通知沿用同一 API Key、批处理和每日用量设置；正文提炼、多个事项、截止和发生时间的规则与其他来源相同。

只读取通知列表和正文，不执行选课、报名、评教、删除通知等操作。正文图片、附件和扫描文件暂不解析。发布时间缺失时显示「发布时间未知」，不把采集时间当作发布日期。原文及教务链接保留；无法识别的日期或适用对象按现有大模型规则进入待确认。

连接后每 5 分钟同步。可选 Windows DPAPI 当前用户加密保存教务系统会话 Cookie 和去重状态；不保存密码或统一认证的全校会话 Cookie。浏览器使用独立临时配置目录。学校当前教务地址为 HTTP，统一认证入口为 HTTPS；程序没有禁用 TLS 证书校验。

断开会删除保存的登录状态并关闭专用学校窗口，已采集事项保留。登录过期会提示重新验证，同一连接保留去重记录。切换其他学生账号前，须先断开当前连接以隔离消息上下文。读取成功与保存成功分别处理，中途失败的原文保留在本机待投递队列，重启后重试，不覆盖用户已完成、归档或编辑的事项。

## 验证边界

已用合成教务页面验证通知列表、正文、发布时间、过期会话、重复同步、超长正文、持久队列恢复及现有大模型处理链路。2026-10-19 已完成真实账号联调：`/jsxsd/framework/xsMain.jsp` 学生个人中心、`/jsxsd/ggly/ysgg_query` 已收公告及 `/jsxsd/ggly/ggly_show?ggid=…` 通知详情均可读取。实际列表共有 20 条，最新发布日期为 2026-09-24；近 7 天为 0 条，近 30 天采集 1 条。发布时间保留至秒，表格式正文与发布元数据分开提取。

该通知已进入配置中的大模型服务，生成 2 项精简正文的待确认事项；适用对象不确定，因此没有直接认定为个人待办。重复同步未增加记录。所有 99 项自动测试及发布检查通过。实际账号当前只有 1 页，分页推进另用合成页面覆盖。

若学校菜单或正文结构改变，程序会提示结构未识别，不会将登录失败或结构不匹配显示成「同步成功、0 条」。0 条新通知时显示列表最新发布日期，方便区分时间范围与采集故障。

实现文件：`collector/csu.mjs`、`collector/csu-browser.mjs`、`collector/csu-accounts.mjs`、`public/csu.js`；服务端账号 API 与其他平台采用相同的本机及浏览器会话限制。
